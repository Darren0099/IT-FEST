# IT FEST — Experimental Interactive Web Design

Arsip eksplorasi desain website dengan tampilan editorial, transisi, dan komponen interaktif untuk latihan pengembangan frontend/kompetisi web design.

## Fokus pengerjaan

- Eksperimen **hero**, section konten, kartu, FAQ, form, dan navigasi.
- Penggunaan CSS terpisah untuk beberapa versi desain dalam `css/`.
- Beragam skrip animasi dan interaksi dalam `js/`.
- Beberapa iterasi halaman, termasuk `IT FEST.html` dan `IT FEST (FIX).html`.

## Teknologi

**HTML**, **CSS**, **JavaScript** serta integrasi library frontend yang direferensikan langsung dari halaman, termasuk **Swiper**, atribut **Finsweet**, dan aset/markup berformat **Webflow**.

## Hasil dan status

Repository ini adalah **arsip prototipe / latihan antarmuka**, bukan aplikasi CMS atau platform manajemen tim. Sebagian markup serta metadata masih berasal dari template Webflow dan sebagian konten halaman menampilkan profil contoh. Konten tersebut tidak boleh dianggap sebagai pengalaman atau prestasi pribadi pemilik repository.

Nilai teknis proyek terletak pada eksplorasi layout dan animasi, bukan integrasi backend atau data pengguna.
